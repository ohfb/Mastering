FUNK BANDIT COSMIC MASTERING — INSTALL

1. Open your GitHub repository: ohfb/Mastering
2. Replace index.html with the included index.html
3. Replace service-worker.js with the included service-worker.js
4. Replace manifest.webmanifest with the included manifest.webmanifest
5. Commit the changes to the main branch.
6. Open:
   https://ohfb.github.io/Mastering/?v=4

If an older version appears:
- Remove the old Home Screen app.
- In iPhone Settings, clear Safari website data for github.io.
- Reopen the ?v=4 address and add it to the Home Screen again.
